QUESTION 01 · ALGORITHM
Write an algorithm to find the sum of the first 10 natural numbers.
BEGIN SET sum = 0 SET i = 1 ...write your logic here...
Model Algorithm:

BEGIN
  SET sum = 0, i = 1
  WHILE i ≤ 10 DO
    sum = sum + i
    i = i + 1
  END WHILE
  OUTPUT sum
END

Result: sum = 55
QUESTION 02 · PSEUDOCODE
Write pseudocode that checks if a number is Odd or Even.
BEGIN INPUT num // Your logic here...
Model Pseudocode:

BEGIN
  INPUT num
  IF num MOD 2 = 0 THEN
    OUTPUT "Even"
  ELSE
    OUTPUT "Odd"
  END IF
END
QUESTION 03 · FLOWCHART
What flowchart symbol is used for a DECISION and what shape does it have?
// Recall your flowchart symbols... START → ? → ? → END
Answer: Diamond (◇)

A DECISION is represented by a diamond shape.
It always has two exits: YES and NO (or TRUE and FALSE).

Other key symbols:
• Oval = START / END
• Rectangle = Process / Action
• Parallelogram = Input / Output
• Arrow = Flow direction
QUESTION 04 · LOOPS
Write pseudocode to print numbers from 1 to 5 using a FOR loop.
FOR i = ? TO ? DO ... END FOR
Model Pseudocode:

FOR i = 1 TO 5 DO
  OUTPUT i
END FOR

Output: 1, 2, 3, 4, 5
